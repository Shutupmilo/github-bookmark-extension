# GitHub Bookmark Saver

Chrome extension for saving GitHub repository, folder, and file URLs as metadata in `Shutupmilo/github-bookmarks/BOOKMARKS.json`.

## Install
1. Open `chrome://extensions` and enable Developer mode.
2. Choose **Load unpacked** and select this repository.
3. Open the extension options.
4. Configure a GitHub fine-grained token with **Contents: Read and write** access to `Shutupmilo/github-bookmarks`.
5. Visit a GitHub repository, folder, or file and click the extension icon.

The extension stores the URL, title, root repository, path, kind, tags, description, notes, and timestamp. It stores metadata only and does not copy repository contents.
